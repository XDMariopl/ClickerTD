# Clicker TD

## Par spēli

**Clicker TD** ir 2D stratēģijas spēle, kas apvieno divus populārus žanrus – **Tower Defense** un **Clicker**. Spēlētāja uzdevums ir aizsargāt savu bāzi no pretinieku viļņiem, izvietojot un uzlabojot torņus, kā arī aktīvi klikšķinot uz pretiniekiem, lai iegūtu resursus un nodarītu bojājumus.

Spēlē ir pieejami vairāki torņu veidi ar unikāliem efektiem, kampaņas režīms, bezgalīgais režīms (Endless Mode), medaļu sistēma un progresa saglabāšana.

## Funkcijas

* 2D Tower Defense spēle ar Clicker mehānikām
* Dažādi torņi ar unikāliem efektiem
* Torņu uzlabošanas sistēma
* Kampaņas režīms ar atbloķējamām kartēm
* Endless režīms ar pieaugošu grūtības pakāpi
* Medaļu un sasniegumu sistēma
* Progresa automātiska saglabāšana
* Audio un spēles iestatījumi

## Lejupielāde

1. Atver projekta GitHub repozitoriju.
2. Dodies uz sadaļu **Releases**.
3. Lejupielādē jaunāko **ClickerTD.zip** versiju.
4. Izpako ZIP arhīvu sev vēlamajā vietā datorā.

## Palaišana

1. Atver izpakoto mapi.
2. Atrodi failu **ClickerTD.exe**.
3. Veic dubultklikšķi uz faila, lai palaistu spēli.
4. Nav nepieciešams instalēt Unity vai atvērt projekta failus.

## Sistēmas prasības

* Operētājsistēma: Windows
* Tastatūra un pele
* Ekrāna izšķirtspēja: ieteicams 16:9 vai 16:10 formāts

## Vadība

* Kreisais peles klikšķis – izvēlēties un novietot torņus
* Kreisais peles klikšķis uz pretiniekiem – veikt uzbrukumu
* Klikšķis uz torņa – atvērt uzlabojumu izvēlni
* ESC – atvērt vai aizvērt noteiktus spēles logus
